# Security reporting

Report suspected vulnerabilities privately to **legal@bytesizedcareers.com**, with
the subject “ByteSized Careers security report”. Do not open a public issue containing
credentials, subscriber information, session/resume tokens, verification codes, or
exploit details that would expose users.

Include the affected revision, a concise description, expected versus observed
behavior, and a minimal reproduction using synthetic data. Redact secrets and personal
information. Do not test destructive actions, enumerate subscribers, bypass access
controls, or send email against the hosted service without explicit authorization.

Source publication does not grant permission to test the live infrastructure. No
bug-bounty payment, response SLA, independent security certification, or legal safe
harbor is promised by this file. The maintainer must verify reports and coordinate
remediation and any disclosure.

For routine data requests or opt-outs, use the same contact address and the public
[privacy notice](https://bytesizedcareers.com/early-access/privacy).
